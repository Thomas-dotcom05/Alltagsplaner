MEIN ESSENSPLANER – INSTALLATION

1. Lade den gesamten Ordner auf einen statischen Webhost hoch (z. B. GitHub Pages, Netlify oder Cloudflare Pages).
2. Öffne danach die veröffentlichte URL auf deinem iPhone/iPad in Safari.
3. Teilen → Zum Home-Bildschirm.
4. Danach startet die Seite wie eine kleine App.

Enthalten:
- Wochenplan Montag–Sonntag
- 3 Mahlzeiten pro Tag
- Auswärts/frei
- automatische Einkaufsliste
- Zutaten zusammenrechnen
- Einkauf abhaken
- 9 Rezepte
- lokale Speicherung auf dem Gerät
