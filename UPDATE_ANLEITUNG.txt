ALLTAGSPLANER V2 – UPDATE AUF GITHUB

Im Repository Alltagsplaner:
1. Add file / Upload files.
2. Diese 3 Dateien hochladen:
   - index.html
   - manifest.webmanifest
   - sw.js
3. GitHub fragt, ob vorhandene Dateien ersetzt werden sollen bzw. zeigt die Änderungen.
4. Commit changes bestätigen.
5. GitHub Pages aktualisiert die App automatisch.
